# Excel Sales Data Analysis

An Excel-based data analytics project completed as part of my
transition into data analytics alongside my frontend development
journey.

## Skills Demonstrated

- Data cleaning
- Duplicate removal
- Data validation
- Data standardization
- Excel formulas
- Data analysis

## Data Cleaning

The dataset was cleaned by:

- Removing duplicate records
- Removing unnecessary spaces
- Standardizing text using Proper Case
- Validating Unit Price and Total Price
- Verifying Quantity × Unit Price = Total Price
